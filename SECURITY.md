# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the repository owner privately through GitHub with a description of the issue, affected files or behavior, reproduction steps, and any suggested mitigation.

The project runs in the browser and does not upload user files. Reports involving malicious NBT files, resource packs, excessive memory use, or unsafe browser behavior are especially useful.
